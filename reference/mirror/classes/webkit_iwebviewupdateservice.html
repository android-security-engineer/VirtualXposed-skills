src/main/java/mirror/android/webkit/IWebViewUpdateService.java

镜像真实类 android.webkit.IWebViewUpdateService$Stub$Proxy，用 Ref 引用对象包装其隐藏成员。

镜像的字段/方法 ​

  • public static RefMethod<String> getCurrentWebViewPackageName

用途 ​

配合 RefClass.load 在运行时绑定到真实 Android 类的对应成员，让 VirtualXposed 以类型安全方式访问这些隐藏 API。详见 反射框架 mirror 与 mirror 总览.
